# The 3AM Fridge Text — entry

A program/v1 entry for the make.fun "The 3AM Fridge Text"
bounty. `main.py` writes one line to `/output/entry.txt` (or
to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).

The text:

> It's 3am. The leftovers from March have achieved consciousness, elected a leader, and are asking when you'll be home.

Only the fridge could send this: it has been awake all night
with the thing it was supposed to preserve, and it reports the
situation the way a night guard would -- factually, at 3am.
A refinement pass grew the draft's flat warning into a small
civilization: the leftovers elected a leader, and their first
diplomatic question is when you'll be home. 118 characters.
